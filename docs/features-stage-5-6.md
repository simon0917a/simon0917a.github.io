# 收藏與路線搜尋

## 收藏

- 收藏內容只包括路線號碼、繁中目的地、方向、服務類別及內部資料來源。
- 不會儲存巴士站、ETA 或使用者位置。
- 資料使用 `localStorage` 的 `香港巴士收藏路線` 鍵保存。
- 點選收藏路線後仍使用當前位置執行自動最近可乘搭站流程。
- 排序使用清楚的上下移動按鈕，次序會一併保存。

## 搜尋

- 搜尋只比較路線號碼的前綴，不比較目的地、站名、地址或地點。
- 搜尋頁沒有原生 `<input>`，只使用自訂大型鍵盤。
- 數字區固定在左側，字母區在右側；字母區使用兩欄及獨立垂直捲動。完整提供 A 至 Z，並將香港路線常見尾碼（包括 M）放在首屏。
- 同一路線不同目的地方向分開顯示；相同路線、方向及目的地的跨來源重複結果會合併。
- 選中結果後直接執行自動最近可乘搭站流程。
- 搜尋頁使用 React 延遲載入，只有進入搜尋分頁才載入鍵盤程式及路線資料。

## 路線詳情

- 自動選擇最近有 ETA 的可乘搭車站後，同時顯示即時到站、實際街道底圖及完整沿途站序。
- 地圖以站點經緯度繪製路線，標示起點、終點和目前查看車站，支援縮放及拖曳。
- 點擊沿途任何車站可切換並讀取該站 ETA。
- 地圖程式延遲載入，只有進入路線詳情時才下載。

## 收藏介面

- 收藏列表只提供進入路線的主要操作，不再顯示上下排序按鈕。
